# Wish Export

Wish Export finds the wish or gacha history URL for supported HoYoverse games and lets you copy it for use with a gacha history tracker.

</div>

## Supported games

- Genshin Impact
- Honkai: Star Rail
- Zenless Zone Zero

## Requirements

- Android 8.0 or later
- Either [Shizuku](https://github.com/RikkaApps/Shizuku) or a rooted device

Shizuku is the recommended option for devices without root access. Install and start Shizuku before using Wish Export.

## How to use

1. Open Wish Export and choose **Shizuku Mode** or **Root Mode**.
2. Tap **Capture**.
3. Open the supported game and go to its wish, warp, or signal history.
4. Wait for Wish Export to find the history URL.
5. Copy the URL and paste it into your preferred gacha history tracker.

Stop the capture when you are finished. If no URL is found, return to the game's history screen and try again.

## Troubleshooting

- **Shizuku is not running:** Open Shizuku, start its service, then try again.
- **Root access is unavailable:** Grant root permission to Wish Export or use Shizuku instead.
- **No URL is detected:** Make sure you opened the in-game wish, warp, or signal history while capture was running.
